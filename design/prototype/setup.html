2 · Add this service’s IP to WeChat2 · 在微信中添加本服务的 IP

Server egress IP (not your computer’s IP):服务器出口 IP（不是你电脑的 IP）： __PUBLIC_IP__

Open the step-by-step guide →打开逐步操作指南 →

Open the official WeChat Official Accounts Platform with an administrator’s account. Find the API IP whitelist in the developer settings; if redirected, use the official developer platform linked there. Add one IP on a new line and keep existing entries.用管理员身份打开官方微信公众号平台。在开发设置中找到 API IP 白名单；若后台提示迁移，请从其链接进入官方开发者平台。另起一行添加本页 IP，保留已有条目。

Do not change login security IPs, business domains or JS domains. Do not reset AppSecret just to follow this guide.不要改登录安全 IP、业务域名或 JS 接口安全域名，也不要为了跟随教程重置 AppSecret。

3 · Check and connect3 · 检查并连接

Connecting sends these WeChat credentials to this Publy server for validation and storage. Only use a server you trust. AppSecret is not saved in browser storage.连接时，公众号凭据将发送至当前 Publy 服务器进行校验并保存。只在你信任的服务中操作；AppSecret 不写入浏览器存储。
