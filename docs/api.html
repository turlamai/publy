The HTTP API behind the draft.草稿背后的 HTTP API。

A small authenticated API for creating WeChat drafts, querying uncertain results, and managing scheduled jobs. It creates drafts only; it never mass-sends or publishes publicly.一组经过鉴权的小型 API：创建公众号草稿、查询未知结果、管理排程任务。它只创建草稿，不群发、不公开发布。

Authentication鉴权

One header.一个请求头。

Every data endpoint requires x-api-key. The admin key manages users/accounts; user keys can only publish to accounts they own and consume their own quota.所有数据接口都需要 x-api-key。admin key 管理用户/账号；用户 key 只能投递自己名下的公众号，并消耗自己的配额。

  https://your-publy-server/v1/quota

POST /v1/publishPOST /v1/publish

The CLI and plugin render Markdown to the HTML payload. If you integrate directly, send the rendered article HTML and attachments yourself. Always send a stable idempotencyKey for retry safety.CLI 和插件会先把 Markdown 渲染成 HTML。若直接集成，需要自己发送渲染后的 HTML 与附件；务必带上稳定的 idempotencyKey 以保证重试安全。

POST /v1/publish
x-api-key: publy_…
content-type: application/json

{
  "account": "My Account",
  "type": "article",
  "title": "A draft title",
  "html": "<div id=\"publy\">…</div>",
  "images": [
    { "name": "cover.png", "contentType": "image/png", "data": "<base64>" }
  ],
  "cover": "cover.png",
  "idempotencyKey": "report-2026-11-09"
}

Success returns { mediaId, deduped, account, title, requestId }. A scheduled request returns { jobId, runAt, scheduled: true }. A lost response returns HTTP 409 DRAFT_OUTCOME_UNKNOWN; do not resend — query /v1/publish-result/:key and check the WeChat draft box. 成功返回 { mediaId, deduped, account, title, requestId }；定时请求返回 { jobId, runAt, scheduled: true }。回执丢失时返回 HTTP 409 DRAFT_OUTCOME_UNKNOWN：不要重发，先查 /v1/publish-result/:key 并核对微信草稿箱。

Outcomes结果语义

Never guess from a timeout.不要用超时猜测结果。

confirmedconfirmed

WeChat acknowledged the draft. The result names the account, title and request ID that were actually submitted.微信已确认创建草稿；结果会带上实际提交的公众号、标题与 request ID。

unknownunknown

The request may have landed. Keep the same request ID, inspect the WeChat draft box, then query and decide. A retry with the same key dedupes if it already exists.请求可能已落地。保留同一个 request ID，检查微信草稿箱后再查询并决定；同 key 重试若已存在会自动去重。

rejected / failedrejected / failed

The server or WeChat explicitly refused. Read the code/message; do not treat this as an unknown outcome.服务端或微信明确拒绝。查看 code/message；这不属于结果未知。

scheduledscheduled

A server-side job was accepted. Jobs found running after a restart are marked interrupted and never auto-resent.服务端已接受排程任务。重启时仍在运行的任务会标记为 interrupted，绝不自动重发。
