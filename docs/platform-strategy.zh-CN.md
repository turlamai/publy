# Publy 产品聚焦 — 2026-11-27

[English](platform-strategy.md) · **简体中文**

桌面端、Web 工作台、Obsidian 插件和 CLI/Skill 均为正式产品入口。桌面端优先 Racket + Glaze（须验证能力）；Web 优先浏览器本地渲染。两者遵循 design/prototype，复用现有 Core 和托管权益，不重复实现业务逻辑。Obsidian 为可选入口。原 Markdown 和附件留在原处，共用渲染、离线检查、预览与本次操作参数。开发跟踪 #118、#119；规划不代表已经交付。

微信公众号草稿箱仍是唯一目的地。不增加公开发布、群发、跨平台分发、模拟微信登录或多目的地框架；不再安排 Typora 专属集成或兼容性项目。普通 Markdown 文件是各客户端的通用输入。

笔记属性保留并跳过，不参与发布配置。插件在投递窗口中询问，Skill 在意图不明确时询问，CLI 投递必须指定类型。选择类型与授权投递是两步。见[工作流](editor-workflows.zh-CN.md)。

优先完善图片保真、源文件不变、安全 HTML、Obsidian 干净安装、预览与请求一致、明确目标账号和结果未知恢复。商户准入、配额、备份恢复与 Commerce/Permit 仍是独立开卖门禁；公开托管结账保持关闭。本决定不更改源码许可，也不代表发版。
