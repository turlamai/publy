简单的使用流程

从笔记到草稿，
每一步都清楚。

不必迁移笔记。先在本地检查和预览，再选择公众号投递，最后到微信后台确认。

WRITE

照常写作

Markdown 和图片留在原来的文件夹，Publy 只读取你选择的文章。

REVIEW

本地预览

预览排版效果并检查图片与封面；会挡住投递的问题，先就地修复。

DELIVER

投递到草稿箱

选定公众号并创建草稿；何时检查、何时公开，由你决定。

把细节照顾好

少一些搬运，
多一些写作。

围绕一篇已有文章，做好检查、排版和草稿投递，让重要的决定始终清晰可见。

投递前检查

本地分级列出必修、建议与通过项，必修项带修复动作；未解决前投递被拦截。检查不联网、不改原文、不创建草稿。

排版

内置文章主题，处理本地图片、代码和公式。

图片消息

结构化 Markdown 渲染成 3:4 主题卡片，逐张排版，进度可见。

结果清楚

区分已确认与结果未知；结果未知不是失败，先核对草稿箱再重试，重试沿用原请求。

凭据托管

公众号 AppSecret 只保存在你的服务端，不下发到客户端；API key 保存在本机。

你的文件

笔记仍由你在原处管理，Publy 不替你建立另一套笔记库。
