# 从零连接微信公众号

[English](wechat-setup.md) · **简体中文**

目标：让 Publy 把你确认的内容送到**自己公众号的草稿箱**。不是群发，也不会自动公开发布。先确认公众号权限，再考虑托管购买；本地预览与复制无需付款、无需公众号密钥。

## 1 · 准备什么，去哪个网站？

在电脑浏览器打开官方[微信公众号平台](https://mp.weixin.qq.com/)，用该公众号管理员或有开发权限的账号登录，并核对当前公众号名称。不要在微信支付商户平台、微信开放平台的移动应用管理或支付宝后台寻找公众号白名单。

需要三样东西：公众号 **AppID**、同一个公众号的 **AppSecret**、Publy 服务器的**出口 IP**。另外，你需要自己的 **Publy API Key** 来登录 Publy；它与 AppSecret 完全不同。

| 内容 | 从哪里取得 | 填在哪里 |
| --- | --- | --- |
| Publy API Key | 开户时保存的 Key；自托管则由运营者创建 | Publy 连接页和 Obsidian 设置 |
| AppID / AppSecret | 微信官方公众号开发设置 | 你信任的 Publy 服务器的连接页 |
| 服务器出口 IP | 当前 Publy 服务的 `/setup`「服务器出口 IP」 | 微信的 **API IP 白名单** |

先在微信后台的接口权限列表确认你的公众号具有所需的**草稿接口和素材上传接口**。接口是否可用以该公众号官方后台实际显示为准；Publy 不能绕过认证或权限限制。只通过 AppID/AppSecret 校验，并不能证明草稿接口已获准使用。如果没有权限，可以继续免费本地预览/复制，托管版提供固定出口与凭据保管，但不会解锁账号本身没有的接口权限。

## 2 · 复制正确的服务器 IP

1. 打开**你使用的 Publy 服务器地址后加 `/setup`**。例如，使用官方托管版的用户打开[官方连接页](https://publy-api.jrtx.site/setup?lang=zh)；自托管用户打开自己的服务地址，不能照抄官方服务 IP。
2. 填入之前保存的 **Publy API Key**，点击「查看我的账户」。首次还没有 Key 时，先在官方连接页注册获取，或由你的自托管运营者提供；不要把管理员 Key 填进普通用户设置。
3. 在第 2 步找到「服务器出口 IP」，点击「复制服务器 IP」。只复制纯 IP，例如示例 `192.0.2.10`（这是文档示例，不能实际使用）。
4. 若显示「IP 未确认」，停止这一步，请运营者确认服务真实出口；不要把电脑 IP、家庭宽带 IP、域名、`https://` 或端口填进去。服务器有多个实际出口时，应由运营者确认完整列表。

## 3 · 在微信添加 API IP 白名单

1. 回到[微信公众号平台](https://mp.weixin.qq.com/)，保持登录在**正确的公众号**。
2. 在左侧展开 **「设置与开发」→ 点击「开发接口管理」**。不要根据名称在「安全中心」随意修改 IP 设置；这两个入口用途需要分别确认。
3. 当前后台会显示 **「开发管理模块迁移通知」**，说明开发接口管理自 **2025 年 12 月 1 日起迁至微信开发者平台**。点击通知正文中的蓝色 **「微信开发者平台」** 链接，进入[官方开发者平台](https://developers.weixin.qq.com/platform/)。看到这份迁移通知后，应继续到新平台，而不是停在旧公众号页面寻找配置框。
4. 进入新平台后，核对右上角选中的公众号名称；如需切换，使用该名称旁的下拉按钮。点击顶部 **「基础信息」**，向下找到 **「开发密钥」**。这里同时显示 **AppSecret** 和 **「API IP 白名单」**，白名单右侧有 **「编辑」**。这就是本教程要操作的位置。
5. 先检查 **「API IP 白名单」** 是否已经包含 Publy 连接页显示的服务器 IP。如果已经有，直接保留，无需重复添加；如果没有，点击右侧 **「编辑」**，将服务器 IP **另起一行加入**。保留原有条目，避免让其他正在使用的工具失效。本步骤只处理 API IP 白名单，AppSecret 的「重置 / 冻结」和下面的域名、消息推送配置保持原状。
6. 按微信页面要求，由管理员扫码或完成验证，再保存。回到列表确认新增的 IP 仍在，而不是只停留在编辑框中。
7. 返回 Publy 连接页，继续检查。若微信返回 `40164` /「IP 不在白名单」，将 Publy 错误信息中**微信实际报告的出口 IP**与白名单逐字核对，再保存后重试。若它与连接页 IP 不同，请联系运营者排查出口变化，不要不断重复添加猜测的 IP。

上述旧后台入口、迁移通知和新平台的「基础信息 → 开发密钥 → API IP 白名单 → 编辑」已根据 2026 年 11 月 24 日的官方页面截图核对。菜单后续可能调整，公众号接口权限仍以该账号实际页面为准。

## 4 · 检查并连接公众号

1. 在微信官方开发设置取得 AppID 和 AppSecret。使用已有且确认正确的 AppSecret；**不要为跟随教程重置密钥**。若无法找回，请让管理员先核对其他工具的使用情况，再按微信官方流程处理；重置会影响其他接入。
2. 回到 Publy `/setup` 第 3 步，填写一个易辨认的昵称、AppID 和 AppSecret。仔细核对浏览器域名；凭据会发送到**当前服务器**用于校验和保存，不要粘贴到聊天、issue 或不明网站。
3. 点击「检查并连接 · 不创建草稿」。出现「已连接：昵称」后，代表本服务已校验凭据与出口 IP，并将该公众号绑定到此 Publy 账户；**不表示已经付款，也不表示草稿接口权限已验证**。
4. 如果连接结果未确认或网络中断，先点击「查看我的账户」核对是否已绑定，再决定是否重试。已有连接会显示昵称，不需要重复绑定。页面成功后会清空 AppSecret；它不会写入浏览器存储。

共享电脑操作完，点击「清除此标签页凭据」，再关闭标签页。Publy Key 只用于此服务的账户访问，请保存在密码管理器中。清除页面凭据不会撤销已复制到其他地方的 Key；需要撤销或轮换时联系运营者。

## 5 · 配置 Obsidian，检查第一篇草稿

1. 按[开始使用](https://publy.jrtx.site/start.html?lang=zh)安装插件。在 Obsidian「设置 → 第三方插件」启用 Publy，再打开「设置 → Publy」。社区目录上架仍待验证，目前用 GitHub Release 附件安装。
2. 「服务器地址」填写刚使用的 Publy 服务根地址（例如 `https://publy-api.jrtx.site`），**不要带 `/setup`、`/hosted` 或 `/v1`**。
3. 「API Key」填写自己的 **Publy API Key**，不是微信 AppSecret；选择刚连接的公众号昵称，再点「测试连接」。插件的连接测试检查 Publy 连接和账户信息，不能代替微信草稿权限检查。
4. 先选一篇无敏感信息的短 Markdown 笔记，本地预览，核对标题、图片、排版和目标公众号。新开发版通过本次操作窗口选择文章/图片配文/卡片；已发布 0.8.7 与开发版能力不完全一致，不要把文档中的新功能当作该版本已交付。
5. 只有当你明确希望创建草稿时，确认目标公众号和内容，再执行投递。这会把内容及媒体发送到所选服务和微信。托管需要当前有效权益，未开通时不要通过重复提交或新建账户绕过。
6. 显示成功后，重新打开[微信公众号平台](https://mp.weixin.qq.com/)，确认公众号名称，在「内容管理 → 草稿箱」（旧版可能直接显示「草稿箱」）核对这篇标题、图片和时间。**看见草稿才完成这次内容投递检查**；是否公开发布由你在微信中另行决定。

## 6 · 出错时怎么继续？

| 看到什么 | 下一步 |
| --- | --- |
| API Key 无效 / 无法确认账户 | 核对服务器地址和原 Key；不要填 AppSecret，不要另买一个账户 |
| `40164` / 需要白名单 | 回到第 3 步，核对微信报告的实际 IP、所选公众号和保存结果 |
| 凭据校验失败 | 核对同一公众号的 AppID/AppSecret、是否已被管理员重置及网络状态；不要把原密钥发给客服 |
| 连接成功但草稿提示无权限 | 在微信官方后台核对该账号的草稿/素材接口权限；本地预览仍可用 |
| 昵称已占用 | 换一个昵称，不改公众号密钥 |
| 已达到账号数量上限 | 查看已连接列表，联系运营者处理；不要反复绑定或额外购买 |
| 结果未知、超时、连接断开 | 保留原请求身份，先用「查询结果」并核对微信草稿箱；不要自动重发 |
| 支付后尚未开通 | 回到同一服务器 `/hosted`，用**原 Publy Key**恢复账户并刷新权益；不要重复付款 |
| 支付提示买卖家账号相同 | 收款账号不能给自己付款。退出收银台；需要由获授权的另一真实买家自行验证，不能靠另建 Publy 账户解决 |
| 更换电脑 | 使用同一服务地址和原 Publy Key，恢复原有公众号与权益；无需重新绑定或重新购买 |

仍无法解决时，在[问题反馈](https://github.com/turlamai/publy/issues)提供版本、系统、错误代码和已脱敏截图。不要上传 AppSecret、API Key、二维码付款凭证中的个人资料或完整日志。涉及已付款订单时，通过运营者确认的私密支持渠道处理，不在公开 issue 发支付身份信息。
