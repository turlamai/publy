Four ways in.四种上手方式。

The Obsidian plugin is the shortest path for writers. The CLI works with Typora or any folder of Markdown. Self-hosting unlocks draft delivery.写作者走 Obsidian 插件最短；Typora 或任意 Markdown 文件夹可用 CLI；自托管服务器负责真正的草稿投递。

1 · Obsidian plugin1 · Obsidian 插件 recommended推荐

Obsidian desktop 1.5+. Preview and copy work without a server; delivery needs your own Publy server.Obsidian 桌面版 1.5+。预览和复制无需服务器；投递需要你自己的 Publy 服务端。

  1. Download the ZIP from the 0.8.7 release.从 0.8.7 Release 下载 ZIP。
  2. Unzip into <vault>/.obsidian/plugins/publy/ and enable it.解压到 <vault>/.obsidian/plugins/publy/ 并启用。
  3. Open a note: preview/copy are local. For drafts, set the server URL and API key in Publy settings.打开笔记即可预览/复制；要投递草稿，在设置里填服务器地址和 API key。

2 · Typora + CLI2 · Typora + CLI

Keep Typora as the editor; run the CLI on the same file. There is no signed installer yet — build from source with Node 22+ and pnpm.继续用 Typora 写作，CLI 读取同一个文件。目前还没有签名安装包，用 Node 22+ 和 pnpm 从源码构建。

git clone https://github.com/turlamai/publy.git
cd publy && pnpm install --frozen-lockfile && pnpm -r build
node packages/cli/dist/index.js check note.md --json
node packages/cli/dist/index.js preview note.md --json --out /tmp/review.html

3 · Agent / CI3 · Agent / CI

Every advertised command supports --json with declared prerequisites and approval requirements. Discovery is offline.所有声明命令都支持 --json，并声明前置条件与授权要求；能力发现完全离线。

publy capabilities --json
publy check article.md --json
publy publish article.md --account "My Account" --json

Agents must obtain explicit approval before creating a draft, retrying or cancelling a job. Unknown outcomes preserve the request ID.Agent 创建草稿、重试或取消任务前必须获得明确授权；结果未知时保留原请求 ID。

4 · Self-host the server4 · 自托管服务器 for delivery投递所需

Linux + Node 22/24. The server stores credentials, creates drafts and never publishes publicly. This is the path behind the Obsidian/CLI "publish" action.Linux + Node 22/24。服务端保管凭据、创建草稿，不做公开发布；Obsidian/CLI 的“投递”就是连它。

  1. Clone and build only the server workspace.克隆并只构建 server 工作区。
  2. Write /etc/publy/server.json (admin key, data dir, WeChat accounts).写 /etc/publy/server.json（admin key、数据目录、公众号账号）。
  3. Install the systemd unit, open /admin, create a user key and test the account.安装 systemd 单元，打开 /admin，创建用户 key 并测试账号连通。

Common questions常见问题

Before your first draft.投第一篇草稿之前。

Do I need to pay?需要付费吗？

No. Local preview, copying rich text, the plugin and a self-hosted server are free. Hosted delivery is not for sale yet.不需要。本地预览、复制富文本、插件和自托管服务都免费；托管投递尚未开卖。

Does Publy publish automatically?Publy 会自动群发吗？

No. It creates a draft in your own Official Account. Publishing or mass-sending stays a manual decision in WeChat.不会。它只在你自己的公众号里创建草稿；公开或群发仍由你在微信后台决定。

Where do my files go?我的文件会被复制走吗？

They stay in your folders. Publy reads the file you select; it does not create a second notebook.留在原文件夹。Publy 只读取你选中的文件，不会另建一套笔记库。

What about API keys?API key 从哪来？

A self-hosted operator creates local users in the admin console. The hosted service is not issuing public keys yet. See the API guide.自托管运营者在后台创建本地用户；托管服务尚未公开发放 key。见 API 指南。
